## Cómo usar esta web

1. **Empieza por el [mapa conceptual](/mapa/)**: ver cómo se conectan los temas hace que cada lección «encaje» en vez de ser una fórmula suelta.
2. **Estudia por unidad** con la barra lateral. Cada página combina: intuición → **caso de uso real** → matemática con **derivaciones paso a paso** (botón «Siguiente paso») → **simuladores y calculadoras** → trampas de examen → **código de scikit-learn** → quiz → conexiones → recursos web.
3. **Practica las decisiones**, no solo las fórmulas: la [guía de modelos](/guia-modelos/) y los [casos de estudio](/casos/) muestran cuándo y por qué usar cada técnica.
4. **Juega con los simuladores antes de leer la fórmula final.** Cada uno está pensado para que *veas* el fenómeno (una lasso que se pega a una esquina, un η que diverge, un γ que crea islas).
5. **Practica con el [generador de ejercicios](/examen/generador/)**, el [laboratorio de Python](/laboratorio/), las preguntas de [«explícalo con tus palabras»](/examen/explicalo/) hasta que los cálculos salgan solos, y usa el [glosario](/glosario/) cuando un término en inglés te frene.
6. **Cierra con el [modo examen cronometrado](/examen/modo-examen/)**, el [banco de preguntas oficial](/examen/banco/), el [simulacro](/examen/simulacro/) y las [flashcards](/examen/flashcards/). Tu progreso se guarda en este navegador.
