## Cómo usar esta web

1. **Empieza por el [mapa conceptual](/mapa/)**: ver cómo se conectan los temas hace que cada lección «encaje» en vez de ser una fórmula suelta.
2. **Estudia por unidad** con la barra lateral. Cada página sigue el mismo orden: intuición → matemática con derivación → **simulador** → trampas de examen → quiz → conexiones → recursos web.
3. **Juega con los simuladores antes de leer la fórmula final.** Cada uno está pensado para que *veas* el fenómeno (una lasso que se pega a una esquina, un η que diverge, un γ que crea islas).
4. **Cierra con el [banco de preguntas oficial](/examen/banco/)**, el [simulacro](/examen/simulacro/) y las [flashcards](/examen/flashcards/). Tu progreso se guarda en este navegador.
