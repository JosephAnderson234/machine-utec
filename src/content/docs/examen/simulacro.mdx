## Problemas de desarrollo

### 1 · Dual del SVM a mano

Puntos $\mathbf{x}_1 = (1,0)$, $y_1 = +1$; $\mathbf{x}_2 = (-1,0)$, $y_2 = -1$. Escribe el dual, resuélvelo y recupera $\mathbf{w}$, $b$ y el margen.

<Solucion>

$\sum\alpha_iy_i = 0 \Rightarrow \alpha_1 = \alpha_2 = \alpha$. Productos: $\mathbf{x}_1^\top\mathbf{x}_1 = \mathbf{x}_2^\top\mathbf{x}_2 = 1$, $\mathbf{x}_1^\top\mathbf{x}_2 = -1$.

$W(\alpha) = 2\alpha - \tfrac12\big(\alpha^2 + \alpha^2 + 2\alpha^2\big) = 2\alpha - 2\alpha^2$. $W' = 2-4\alpha = 0 \Rightarrow \alpha = 0.5$, $W = 0.5$.

$\mathbf{w} = 0.5(1,0) - 0.5(-1,0) = (1,0)$; $b = y_1 - \mathbf{w}^\top\mathbf{x}_1 = 0$. Frontera $x_1 = 0$; banda $2/\|\mathbf{w}\| = 2$ (la distancia entre los puntos). Primal $\tfrac12\|\mathbf{w}\|^2 = 0.5 = W$ ✓.

</Solucion>

### 2 · Gradiente de la cross-entropy

Un punto $\mathbf{x} = (1, 2)$, $y = 0$, con $\mathbf{w} = (1, 1)$, $b = -1$. Calcula $p$, la pérdida y $\nabla_\mathbf{w}\ell$. Da un paso con $\eta = 0.5$.

<Solucion>

$z = 1+2-1 = 2$, $p = \sigma(2) = 0.881$. $\ell = -\log(1-0.881) = 2.127$.

$\nabla_\mathbf{w}\ell = (p-y)\mathbf{x} = 0.881(1,2) = (0.881, 1.762)$; $\partial\ell/\partial b = 0.881$.

Paso: $\mathbf{w} = (1,1) - 0.5(0.881, 1.762) = (0.560, 0.119)$, $b = -1-0.44 = -1.44$. Nuevo $z = 0.560+0.238-1.44 = -0.642$, $p = 0.345$: ya lo clasifica bien.

</Solucion>

### 3 · Descomposición sesgo–varianza con números

Para un punto $x$, la verdad es $f(x) = 10$ y el ruido $\sigma^2 = 4$. Cinco re-entrenamientos predicen 12, 13, 11, 12, 12. Calcula sesgo², varianza y error esperado.

<Solucion>

$\bar f = 60/5 = 12$. Sesgo² $= (12-10)^2 = 4$. Varianza $= \frac15(0+1+1+0+0) = 0.4$. Error esperado $= 4 + 0.4 + 4 = 8.4$. Domina el sesgo: el modelo subajusta en este punto.

</Solucion>

### 4 · Poda: ruta completa

Verifica los tres quiebres de la ruta de los diez puntos: $2/15$, $16/105$, $3/14$.

<Solucion>

Costos $C_\alpha$: 4 hojas $4\alpha$; 3 hojas $\tfrac2{15}+3\alpha$; 2 hojas $\tfrac27+2\alpha$; 1 hoja $\tfrac12+\alpha$.

- 4 vs 3: $4\alpha = \tfrac2{15}+3\alpha \Rightarrow \alpha = \tfrac2{15}$.
- 3 vs 2: $\tfrac2{15}+3\alpha = \tfrac27+2\alpha \Rightarrow \alpha = \tfrac27-\tfrac2{15} = \tfrac{30-14}{105} = \tfrac{16}{105}$.
- 2 vs 1: $\tfrac27+2\alpha = \tfrac12+\alpha\Rightarrow\alpha = \tfrac12-\tfrac27 = \tfrac3{14}$.

</Solucion>
