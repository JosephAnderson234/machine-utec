## Un score por clase

Para $K$ clases, cada una tiene sus propios pesos y score lineal $z_k = \mathbf{w}_k^\top\mathbf{x}+b_k$. La **softmax** los convierte en probabilidades positivas que suman 1:

$$
p_k = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}},\qquad \sum_k p_k = 1,\qquad \hat y = \arg\max_k p_k
$$

Cada frontera entre un par de clases sigue siendo **una recta** (donde $z_i = z_j$): el plano queda partido en regiones convexas.

- **Pérdida:** cross-entropy con la etiqueta en **one-hot** ($y_k = 1$ solo para la clase verdadera): $\ell = -\sum_k y_k\log p_k = -\log p_{\text{verdadera}}$.
- **Gradiente:** $\partial\ell/\partial z_k = p_k - y_k$: otra vez la forma «residual» $\mathbf{p}-\mathbf{y}$.

El dataset `digits` del notebook 04d tiene imágenes de 8×8 píxeles (64 features) y 10 clases. Una regresión logística multinomial (softmax) aprende **10 vectores de pesos de 64 números**: cada uno, visto como imagen 8×8, parece una «plantilla» difusa del dígito. Para una imagen nueva, cada clase calcula su score $z_k = \mathbf{w}_k^\top\mathbf{x}+b_k$ (cuánto se parece a su plantilla) y softmax los convierte en probabilidades.

- Accuracy de test típica ≈ 96%: un modelo **lineal** basta porque los píxeles ya separan bastante bien las clases.
- La matriz de confusión 10×10 muestra qué se confunde (8 con 1, 9 con 3…): la diagonal son los aciertos, como en el caso binario.
- Con un SVM RBF o una red neuronal se llega a ≈99%: el precio es menos interpretabilidad.

## La sigmoide es softmax con K = 2

Con dos clases: $p_1 = \frac{e^{z_1}}{e^{z_0}+e^{z_1}} = \frac{1}{1+e^{-(z_1-z_0)}} = \sigma(z_1-z_0)$. Solo importa la **diferencia** de scores (sumar una constante a todos no cambia nada), así que la logística binaria con $z = z_1 - z_0$ es el caso particular. Un score por clase, softmax, cross-entropy: **todo se traslada**.

:::note[En la práctica]
Se implementa de forma estable restando $\max_k z_k$ antes de exponenciar (no cambia el resultado y evita desbordes). En scikit-learn, `LogisticRegression` multiclase usa softmax (multinomial). El notebook 04d la aplica a los dígitos 0–9.
:::

## En código

```python
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.metrics import confusion_matrix

X, y = load_digits(return_X_y=True)                     # 1797 imágenes, 64 píxeles
X_tr, X_te, y_tr, y_te = train_test_split(X, y, stratify=y, random_state=0)
clf = make_pipeline(StandardScaler(), LogisticRegression(max_iter=2000))  # multinomial
clf.fit(X_tr, y_tr)
print(clf.score(X_te, y_te))                            # ≈ 0.96
P = clf.predict_proba(X_te[:1])                         # 10 probabilidades que suman 1
W = clf[-1].coef_.reshape(10, 8, 8)                     # cada fila = «plantilla» 8×8
```
